# @businessos/api

NestJS 12 HTTP API (ESM, Vitest).

| Command                                  | What it does             |
| ---------------------------------------- | ------------------------ |
| `pnpm --filter @businessos/api dev`      | Start with file watching |
| `pnpm --filter @businessos/api build`    | Compile to `dist`        |
| `pnpm --filter @businessos/api test`     | Run unit tests           |
| `pnpm --filter @businessos/api test:e2e` | Run end-to-end tests     |

Configuration comes from the repository root `.env` (see `.env.example`).
